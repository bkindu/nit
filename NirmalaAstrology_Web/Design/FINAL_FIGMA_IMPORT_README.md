# Nirmala Astrology — Final Figma Import Pack

This is the final logo-matched UI/UX pack for the Nirmala Astrology MVC project.

## Import order

1. Import `NirmalaAstrology_Figma_All_Screens_Brand.svg` into Figma. This is the consolidated all-screens storyboard.
2. Import `NirmalaAstrology_Figma_Light_Dashboard.svg` for the light dashboard reference.
3. Import `NirmalaAstrology_Figma_Dark_Kundli_Result.svg` for the dark calculation/result reference.
4. Import `NirmalaAstrology_Logo_Reference.png` as the reusable brand logo component.
5. Use `NirmalaAstrology_All_Screens_Figma_Spec.md` for route-by-route frames and responsive variants.
6. Use `NirmalaAstrology_UIUX_Design_Spec.md` for tokens, accessibility, component behavior and MVC implementation guidance.

## Covered screen families

**Public:** Home, About, Contact, Zodiac, Articles, Reports/Pricing, Appointment, Payment, Login, Register, Forgot Password, Access Denied and Error states.

**User/operator:** Workspace, Birth Data steps, Kundli Result, Official Report, Print, Records, Account, Change Password, Match Making, Numerology, Gochar, Muhurat, Vivah Muhurta, Varsh Phal, Lal Kitab and Palmistry.

**Admin:** Dashboard, Birth Data, Kundli/Report queue, Records, Appointments, Appointment Details, Articles, Places, Account and role/error states.

## Brand rule

Use the supplied logo as the source of truth. Use vermilion/red, deep maroon, gold and saffron cream. Keep gold for primary actions and active indicators. Do not revert to the previous purple-first theme.

## Prototype flow

Home → Birth Data → Kundli Result → Official Report

Home → Appointment → Payment

Login → Workspace → Records / Appointments / Articles
