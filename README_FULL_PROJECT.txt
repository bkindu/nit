NIRMALA ASTROLOGY - COMPLETE MVC PROJECT
=========================================

This archive contains the complete ASP.NET MVC 5.3 / .NET Framework 4.8 project and all accumulated source, view, JavaScript, CSS, SVG, SQL, configuration, numerology, Panchang, Kundli, and PDF/letterhead changes.

OPENING THE PROJECT
-------------------
1. Extract the ZIP to a writable folder, for example E:\NirmalaAstrology.
2. Open NirmalaAstrology.sln in Visual Studio on Windows.
3. Restore NuGet packages from packages.config. The archive includes the packages folder, but Visual Studio may still refresh package references.
4. Ensure the ASP.NET and web development workload and .NET Framework 4.8 developer pack are installed.
5. Clean Solution, delete bin and obj if present, and Rebuild Solution.

MYSQL CONFIGURATION
-------------------
The current Web.config connection entry is named NirmalaAstrologyDB and points to:
Server=127.0.0.1;Port=3306;Database=indu_astro;Uid=root

Update the password in Web.config if the local MySQL root password differs. Execute the SQL files under NirmalaAstrology_Web\App_Data in MySQL Workbench, including the stored-procedure installation script, after the indu_astro schema is available.

IMPORTANT BUILD NOTE
--------------------
Do not include or commit .vs, bin, or obj folders. They are generated by Visual Studio and are intentionally excluded from this clean archive. If the project reports Microsoft.WebApplication.targets missing, install the Visual Studio ASP.NET/web workload and build with Visual Studio MSBuild rather than the standalone .NET SDK.

FEATURES INCLUDED
-----------------
Kundli calculation and SVG North Indian chart binding, detailed horoscope/Panchang output, legacy Panchang fields, numerology module, optimized place search, global loading indicators, server-side birth-data session preservation, dedicated birth-data route, A4 letterhead print/PDF export, normalized MySQL scripts, and compatibility stored procedures.
